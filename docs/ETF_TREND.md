## 0. 为什么换到 ETF，以及为什么这么设计

`PATH_200K.md` §8 用实测否掉了「8 因子横截面选股」，否掉的机制是四条：
估计误差压倒优化（DGU 2009）、信噪比 < 1、广度被 5 只锁死、摩擦吃光毛 alpha。
新设计必须**逐条**绕开它们，否则只是换皮。

| 已证伪的机制 | 本设计的对策 |
|---|---|
| 横截面选股在最流动池子里没有 alpha | **不做横截面选股**。用时间序列（绝对）动量决定"是否持有" |
| 5 只持仓 → 广度 `BR_eff = N/(1+(N-1)ρ) ≈ 1.7` | **广度来自资产类别 × 时间**：10 只 ETF 覆盖 4~5 个低相关类别 |
| 36× 换手 → 摩擦 6%/年 | **月末调仓**，目标换手 ≤ 4×/年 |
| 股票卖出 0.05% 印花税 + 5 元最低佣金 | **ETF 免印花税、免过户费**，一手仅 100 份（几百元） |
| 集中持仓 → σ≈35% → 回撤 59% | **波动率目标**（Moreira & Muir 2017）+ 多资产分散 |
| 空仓只能拿 0 现金收益 | 空仓腿 = **货币 ETF**（有票息、T+0、无印花税） |

**理论出处**：Moskowitz, Ooi & Pedersen (2012) 时间序列动量；
Faber (2007) 趋势过滤战术资产配置；Moreira & Muir (2017) 波动率管理组合；
Asness, Frazzini & Pedersen (2012) 风险平价；Fernholz & Shay (1982) / Booth & Fama (1992)
分散化收益。

## 2. 信号与权重（全部预先固定，不调参）

```
动量      mom_i  = P_i(t) / P_i(t-252) - 1          （12 个月绝对动量）
趋势过滤   P_i(t) > MA200_i(t)                        （Faber 式趋势）
绝对门槛   mom_i > mom_cash                           （打赢货币 ETF 才持有）
PIT 资格   上市满 253 个交易日  且  trailing 20 日均成交额 ≥ 2000 万
选品       全部通过者等权（不做横截面排序）        ← top_k = None
风险缩放   scale = min(1, 12% / σ_portfolio)          （σ 用 trailing 60 日）
           σ_portfolio 由当前目标权重合成的历史收益序列估计
空仓       w_cash = 1 − Σ w_risky
调仓       每 21 个交易日；非调仓帧只"向目标靠拢"
```

**自由度极低**：只有 lookback / ma_window / target_vol / rebalance 四个参数，
且全部取整数值（252/200/0.12/21），没有经过任何搜索。

## 4. Kill criteria（与 `PATH_200K.md` §3.3 一致，先写后跑）

| 判据 | 阈值 |
|---|---|
| 年化收益（扣全部成本） | **≥ 10%** |
| Sharpe | **≥ 0.5**，且 bootstrap 5% 下界 **> 0** |
| 最大回撤 | **≤ 25%** |
| 年化单边换手 | **≤ 4×** |
| 年化 > 买入持有 510300 | 必须成立 |

**任何一条不过 → 该设计作废，不调参抢救。**

## 5. 验证协议（防自我欺骗）

1. **报告区间 2014-01-01 → 2026-10**（约 12.8 年）；喂入数据自 2012-01-01 起，
   策略在其上自然预热，评价只用报告区间。
2. **移动块 bootstrap**（block=21）给 Sharpe 打 5%~95% 置信区间。
3. **关键消融**：`--no-trend`（去掉择时与绝对门槛，永远等权持有同一菜单）。
   **这是本次最重要的科学对照** —— 若"择时"打不过"不择时"，则择时是装饰。
4. **参数邻域敏感性**：lookback ∈ {126,189,252}、rebalance ∈ {21,63}、
   vol target 开/关、等权 vs 逆波动率。要求**邻域内不崩**。
5. **成本压力测试**：滑点 3bp → 10bp。
6. 基准：买入持有 510300 / 510050 / 518880。

## 6. 结果（2026-10-16 实跑，报告区间 2014-01 → 2026-10，12.33 年）

### 6.1 预登记主策略（lookback=252，月末调仓，趋势+波动目标）

| 指标 | 实测 | kill criterion | |
|---|---|---|---|
| 总收益 / 年化 | +192.80% / **+9.10%** | ≥ 10% | ✗ |
| Sharpe | **0.86** | ≥ 0.5 | ✓ |
| bootstrap Sharpe 5% 下界 | **0.39** | > 0 | ✓ |
| 最大回撤 | **21.33%** | ≤ 25% | ✓ |
| 年化单边换手 | **2.67×** | ≤ 4× | ✓ |
| 年化 > 买入持有 510300 | 9.10% vs 8.70% | — | ✓ |

**通过 5/6 —— 差在年化 9.10% < 10%。按预登记规则，主策略判定为"未达标"。**

### 6.2 基准对比（同区间，含风险调整）

| 组合 | 总收益 | 年化 | Sharpe | 最大回撤 | 波动 |
|---|---|---|---|---|---|
| 买入持有 510300 沪深300 | +179.75% | +8.70% | 0.45 | **52.97%** | 26.71% |
| 买入持有 510050 上证50 | +185.23% | +8.87% | 0.46 | 52.76% | 25.61% |
| 买入持有 510500 中证500 | +132.04% | +7.07% | 0.38 | 65.77% | 28.25% |
| 买入持有 518880 黄金 | +254.06% | +10.80% | 0.75 | 30.52% | 15.20% |
| **等权多资产（月度调回，无择时）** | **+224.67%** | **+10.02%** | **0.73** | **28.54%** | 14.65% |
| 预登记主策略 | +192.80% | +9.10% | 0.86 | 21.33% | ~10.6% |

> **主策略的年化低于"什么都不做、只等权持有"0.92pp**；只在 Sharpe（+0.13）与回撤（−7.2pp）上占优。

### 6.3 消融（本轮最重要的科学对照）

| 变体 | 年化 | Sharpe | 最大回撤 | 换手 |
|---|---|---|---|---|
| main：趋势 + 波动目标 | 9.10% | 0.86 | 21.33% | 2.67× |
| `--no-trend`：仅波动目标 | 8.41% | 0.72 | 20.25% | 1.14× |
| `--no-vol-target`：仅趋势 | 9.56% | 0.68 | 32.17% | 2.28× |
| `--no-trend --no-vol-target`：都不做 | 9.89% | 0.67 | 27.06% | 0.49× |
| `--weighting inv_vol`：逆波动率 | 7.28% | **1.06** | **11.57%** | 1.84× |

**趋势择时的贡献符号不稳定**：有波动目标时 +0.69pp/年，去掉波动目标时 **−0.33pp/年**；
且**两种配对下都让回撤变差**（+1.1pp / +5.1pp）。→ **趋势择时是噪声，不是 edge。**
这与上一轮"动态因子权重"消融的失败模式**完全一致**。

**波动率目标是唯一贡献方向一致的成分**：Sharpe +0.05~+0.18，回撤 −6.8~−10.8pp，
代价是年化 −0.5~−1.5pp（Moreira & Muir 2017 的效应）。

### 6.4 决定性检验：能否区别于朴素等权？

对每个变体做**配对块自举**（block=21）求 `Sharpe(策略) − Sharpe(等权多资产)`：

| 变体 | Sharpe 差（中位） | 5% ~ 95% | 判定 |
|---|---|---|---|
| main | +0.10 | −0.24 .. +0.45 | 跨 0 |
| --no-trend | −0.01 | −0.18 .. +0.17 | 跨 0 |
| --no-vol-target | −0.09 | −0.41 .. +0.23 | 跨 0 |
| inv_vol | +0.30 | −0.11 .. +0.71 | 跨 0 |
| lookback=126 | +0.26 | −0.14 .. +0.68 | 跨 0 |

**全部跨 0。择时与波动目标都未能在统计上区别于"朴素等权持有"。**

### 6.5 等权多资产基准的稳健性（`tools/etf_robust.py`）

| 检验 | 年化 | Sharpe | 最大回撤 |
|---|---|---|---|
| 全菜单（11 只） | +10.02% | 0.73 | 28.54% |
| **剔除黄金** | +9.79% | 0.66 | 31.75% |
| **剔除海外（恒生/纳指/标普）** | +8.46% | 0.57 | 37.86% |
| 剔除债券 | +10.81% | 0.68 | 32.08% |
| **仅 A 股宽基（5 只）** | +7.99% | **0.43** | **57.83%** |
| 全菜单 + 12% 波动目标 | +8.81% | **0.79** | **18.32%** |

- **不是黄金撑起来的**（剔金只掉 0.23pp/年）。
- **价值来自跨资产类别**：砍掉海外就掉 1.56pp/年、回撤升到 37.9%；只留 A 股宽基则 Sharpe 掉到 0.43、
  回撤 57.8%——**退化成上一轮那个失败策略的形状**。
- 子区间稳定：2014-2019 年化 +11.84%（Sharpe 0.80）；2020-2026 年化 +8.44%（Sharpe 0.66）。
- **起始日敏感**：2013 起 +10.18%，2014 起 +10.02%，2015 起 +8.53%，2016 起 +7.75%，
  2017 起 +8.07%，2018 起 +8.01%。**10% 这个数在区间高端，晚起步只有 ~8%。**

### 6.6 结论（不改预登记判据）

1. **预登记主策略未达标**（年化 9.10% < 10%），按规定作废，不做调参抢救。
2. **但本轮找到了一个真正可用的东西**：`等权多资产 ETF + 月度调回`（年化 +10.02%、
   Sharpe 0.73、回撤 28.54%、换手 0.49×）——**它跑赢沪深300 买入持有（8.70%/0.45/52.97%）
   在风险调整后是压倒性的，且稳健**（不依赖黄金、跨子区间稳定）。
3. **"择时"这一层没有可证伪的价值**：趋势与波动目标都无法在统计上区别于朴素等权。
   能站住的只有两件**不需要预测**的事：**跨资产分散** 与 **波动率控制**。
4. **诚实的短板**：等权多资产回撤 28.54% > 25% 门槛；加 12% 波动目标后可压到 18.32%
   且 Sharpe 升到 0.79，但年化降到 8.81%。**收益与回撤之间是要取舍的，不是免费的。**
5. **偏误声明**：菜单是今天的存续 ETF，退市 ETF 缺失；2014-2026 对多元化组合是友好区间
   （纳指 +20.45%/年、标普 +14.77%/年、黄金 +10.80%/年）。**未来收益不保证复制。**
